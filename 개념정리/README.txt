[2. 스마트폰 출퇴근용으로 따로 웹에 올리기 (10초 완료)]
- 방법 A (가장 빠름 · 무료):
  https://app.netlify.com/drop 접속 후 이 '개념정리' 폴더를 통째로 드래그&드롭
  → 즉시 스마트폰 접속 URL 발급 (로그인/서버 설정 불필요)
- 방법 B (GitHub Pages 별도 저장소):
  새 GitHub 저장소에 이 폴더 안의 4개 파일(index.html, styles.css, app.js, concept_data.js)만
  올리고 Settings → Pages 에서 main 브랜치 활성화
